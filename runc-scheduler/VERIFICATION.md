# 本地验证记录

本次更新验证日期为 2026 年 10 月 8 日，交付版本为 0.1.2（cgroup v1/v2 适配）。环境为 Windows amd64，Go 工具链为官方 Go 1.27.1；下载归档的 SHA256 已与官方发布元数据核对。源码声明最低 Go 1.22，未另行测试每个历史工具链版本。

|---|---|---|

| `go vet ./...` | 通过 | 本地静态检查 |
| Linux amd64、arm64、riscv64 构建 | 全部成功 | Linux 代码可以交叉编译为这些架构 |
| Windows amd64 构建 | 成功 | 控制服务和 CLI 可供当前环境执行 |
| 实际控制进程与 CLI 冒烟测试 | 通过 | 三个模拟节点通过 HTTP 注册并获得不同任务；v1/v2 节点字段和任务记录在控制进程重启后保持 |
| Bash 语法检查 | 通过 | 编译、安装、rootfs 准备及 MPI launcher 脚本语法正确 |

| JSON 配置与示例解析 | 9 个文件通过 | 配置与工作负载示例为合法 JSON |

当前环境未配置 Linux/WSL、runc 或 Open MPI，也未连接用户的物理机器。因此没有把 Linux 容器创建、cgroup 限额、实机 HPA、跨设备 MPI 或 MPI 性能计为已经通过。C 程序由部署节点的 `prepare-mpi-rootfs.sh` 使用实际 MPI 编译器构建。

在部署节点接入后，按 [逐项测试说明](docs/testcases.md) 分别执行 testcases/01_*.py 至 13_*.py。实机测试没有模拟 runtime 模式；辅助库不含批量执行入口。单部署节点的反亲和报告为 PARTIAL，跨节点部分标明 SKIP；MPI 标记单设备或跨设备通信范围，性能未达阈值时明确报告未达标。

新增的 openEuler 原生编译、环境检查和 MPI rootfs 构建脚本已通过 Bash 语法检查。Go 1.27.1 riscv64 归档及 Open MPI 4.1.8 源码的校验值与官方发布页核对。没有在本地执行 DNF、chroot、mount、systemd 或 RISC-V 原生编译；这些步骤需在实际 openEuler 设备上确认。

v1 指标路径/单位测试使用挂载记录与文件读取测试替身，未读取真实 Linux cgroup，也未执行真实 runc state。Linux Runtime 的实际调用已交叉编译通过，端到端功能须在服务器验证；没有将这些单元检查表述为实机测试通过。

本地 Go 测试输出保存在 `test-results/go-test.jsonl`。二进制校验值保存在 `bin/SHA256SUMS`。
